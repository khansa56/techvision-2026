## 📖 About The Project

**TechVision 2026** is a fully responsive, front-end website designed for a university technology event. It brings together students, developers, and innovators to explore **web development**, **artificial intelligence**, and **student innovation**.

The site features a modern gradient hero section, smooth navigation, an event schedule with PDF download, and a demonstration registration form — all built with **pure HTML, CSS, and Vanilla JavaScript** (no frameworks, no build tools).

> 💡 *This is a student project demonstration created for a Web Technology assignment.*
