# TechVision 2026 Website

A responsive multi-page front-end website prepared for the Web Technology theory/practical assignment.

## Pages
- `index.html` — Home page
- `about.html` — Event overview
- `schedule.html` — Sample programme and PDF link
- `contact.html` — Contact details and demonstration registration form

## Folders
- `css/style.css` — Responsive styling
- `js/script.js` — Mobile navigation and demonstration form interaction
- `images/logo.svg` — Project logo asset
- `documents/schedule.pdf` — Sample programme PDF

## Run locally
Open `index.html` in a browser. For best testing, use a local development server if available.

## InfinityFree deployment
1. Create/sign in to your InfinityFree account and create a hosting account.
2. Open File Manager and enter the website's `htdocs` directory.
3. Upload the *contents* of this project folder (not an extra nested `TechVision` folder).
4. Ensure `index.html` is directly inside `htdocs`.
5. Visit the hosting subdomain and test all pages, styles, JavaScript, images, and the schedule PDF.
6. Configure HTTPS/SSL using the hosting dashboard's available options and test the HTTPS URL.

## Important
This is a static front-end demo. The contact form shows a browser-side confirmation only; it does not save or email submitted details. Replace sample event contact information with approved details before public use.
